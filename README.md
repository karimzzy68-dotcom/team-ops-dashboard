A modern, high-performance operations and performance tracking dashboard engineered for agencies, growth teams, and customer-acquisition workflows.

---

## ⚡ Overview

Convix provides real-time agency metric intelligence, targets tracking, and media campaign analytics designed with an editorial aesthetic and clean component architecture.

### ✨ Key Features
- **Real-time Performance Gauge**: Custom SVG analytics gauge with dynamic threshold indicators.
- **Conversion & Click Analytics**: Real-time tracking of impressions, clicks, and month-to-date targets.
- **Video Campaign Monitoring**: Live reporting of video impressions, starts, and audience engagement retention.
- **Modern Design System**: Built with modern typography, frosted glass overlays, and fully responsive layouts.

## 🚀 Quickstart

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone git@github.com:karimzzy68-dotcom/team-ops-dashboard.git
cd team-ops-dashboard

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
